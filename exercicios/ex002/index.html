Parágrafos e quebra de linha

Para criar um parágrafo, utilizamos a tag <p>

Para criar uma quebra de linha, utilizamos a tag <br>

Podemos usar a tag <br> para criar uma quebra de linha dentro de um parágrafo, como neste exemplo:

Este é um parágrafo com uma quebra
de linha entre as palavras "quebra" e "de"

Símbolos especiais:

  • ® - Marca registrada
  • © - Direitos autorais
  • ™ - Marca comercial
  • € - Símbolo do euro
  • $ - Símbolo do dólar
  • £ - Símbolo da libra esterlina
  • ¥ - Símbolo do iene
  • ¢ - Símbolo do centavo
  • δ - Símbolo grego delta
  • α - Símbolo grego alfa
  • π - Símbolo grego pi
  • ↑ - Seta para cima
  • ↓ - Seta para baixo
  • ← - Seta para a esquerda
  • → - Seta para a direita
  • & - E comercial
  • < - Menor que
  • > - Maior que
  • " - Aspas duplas
  • ' - Aspas simples
